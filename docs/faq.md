# Frequently Asked Questions

## Project Questions

Question: Can I edit a submitted project?
Answer:
No. Submitted projects are locked until workflow rules allow editing again.

Question: Can I edit a revision requested project?
Answer:
Yes.

Question: Why is my project read-only?
Answer:
The project is likely in a locked workflow state.

Question: Why can I not submit my project?
Answer:
Possible reasons:
- incomplete data
- invalid project state
- session issue

## Review Questions

Question: Can Admin review their own projects?
Answer:
No.

Question: Why are review buttons disabled?
Answer:
Possible reasons:
- missing remarks
- incorrect workflow state
- permission restrictions

## Studio Questions

Question: Why can I not place a marker?
Answer:
Possible reasons:
- locked project
- expired session
- invalid workflow state

## Chatbot Questions

Question: What if the chatbot does not know the answer?
Answer:
The chatbot should only answer based on available documentation.
