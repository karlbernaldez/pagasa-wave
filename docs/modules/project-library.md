# Project Library Module

## Purpose
The Project Library is the central workspace for managing forecast projects.

## Common Questions

### How do I create a project?
Answer:
1. Open the Project Library.
2. Select create new project.
3. Enter required project information.
4. Save the draft.
5. Open the project in Studio for editing.

### What can I do in the Project Library?
Users can:
- create projects
- search projects
- filter by status
- sort project listings
- open existing projects
- review project summaries
- track workflow progress

### Why can't I edit a project?
Possible reasons:
- the project is under review
- the project has been approved
- workflow permissions restrict editing
- the project is locked by workflow state

### What statuses might I see?
Examples:
- Draft
- Submitted
- Under Review
- Revision Requested
- Approved
- Published
- Rejected
