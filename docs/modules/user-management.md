# User Management Module

## Purpose
User management controls access roles and permissions.

## Common Questions

### What roles exist?
Examples:
- Forecaster
- Admin

### What does a Forecaster do?
Answer:
Creates and updates forecast projects, submits work, and responds to review requests.

### What does an Admin do?
Answer:
Reviews projects, manages approvals, requests revisions, and publishes outputs.

### Why can't I access a feature?
Possible reasons:
- insufficient permissions
- role restrictions
- account configuration
