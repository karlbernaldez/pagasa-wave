# Notifications Module

## Purpose
Notifications inform users about workflow events and project activity.

## Common Questions

### What notifications can appear?
Examples:
- project submitted
- revision requested
- project approved
- project rejected
- project published

### Why did I receive a notification?
Answer:
A project workflow event likely occurred that requires awareness or action.

### Can notifications require action?
Answer:
Yes. Some notifications may indicate review requests or workflow changes.
