# Studio Module

## Purpose
Studio is the interactive forecast map editing workspace.

## Common Questions

### Question: What is Studio?
Answer:
Studio is where users create and edit forecast chart content.

### Question: What can I do in Studio?
Answer:
Users can:
- place markers
- draw annotations
- manage map layers
- edit forecast content
- save changes

## Editing Features
Studio supports:

- marker placement
- annotation drawing
- layer organization
- forecast feature editing

## Read Only Behavior

Question: Why is Studio read-only?
Answer:
Studio becomes read-only when workflow status prevents editing.

Common locked states:
- Submitted
- Under Review
- Approved
- Published
- Archived

## Common Problems

### Question: Why can I not place markers?
Answer:
Possible reasons:
- project is locked
- session expired
- invalid project state

### Question: Why are tools disabled?
Answer:
Editing may be restricted by workflow rules.
