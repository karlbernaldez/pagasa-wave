# Review Module

## Purpose
The Review module allows Admin users to inspect submitted forecast projects.

## Common Questions

### Question: What is the Review module?
Answer:
The Review module is used for project evaluation and workflow decisions.

### Question: Who can review projects?
Answer:
Admin users.

## Review Actions
Admin users can:

- inspect projects
- compare revisions
- add comments
- request revision
- approve projects
- reject projects
- publish approved projects

## Diff Mode
Question: What is Diff Mode?
Answer:
Diff Mode compares project versions to identify changes.

## Common Problems

### Question: Why is a review action disabled?
Answer:
Possible reasons:
- required remarks are missing
- invalid workflow state
- insufficient permissions
- self review restrictions
