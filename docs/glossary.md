# WaveLab Glossary

## Forecast Workflow Terms

### Draft
Definition:
A project that is still being prepared and can be edited by the Forecaster.

### Submitted
Definition:
A project that has been sent for Admin review and is no longer editable by the Forecaster.

### Under Review
Definition:
A project currently being reviewed by an Admin.

### Revision Requested
Definition:
A project returned to the Forecaster for required changes.

### Approved
Definition:
A project that passed review and is ready for publication.

### Rejected
Definition:
A project that did not pass review.

### Published
Definition:
A finalized forecast product that is no longer editable.

### Archived
Definition:
A stored project retained for history and no longer actively edited.

## Platform Terms

### Project Library
Definition:
The area where users manage forecast chart projects.

### Studio
Definition:
The interactive map editing workspace used for creating and editing project annotations.

### Review Modal
Definition:
The Admin review interface used to inspect, compare, and evaluate projects.

### Preview Mode
Definition:
A review mode showing the current project state.

### Diff Mode
Definition:
A comparison mode showing differences between project versions.

### Annotation
Definition:
A saved visual map feature such as markers, drawings, symbols, or forecast notes.

### Marker
Definition:
A specific map symbol placed on the forecast workspace.

### Layer
Definition:
A map visualization grouping used to organize forecast annotations.

## Marine Forecast Terms

### Marine Forecast
Definition:
A forecast describing expected marine or ocean conditions.

### Wave Height
Definition:
The height of forecasted wave conditions represented in marine products.

### Wave Direction
Definition:
The direction from which wave energy or wave movement is represented.

### Forecast Product
Definition:
A finalized forecast chart or operational output prepared for publication.

### Review Remark
Definition:
A comment added by an Admin during review to explain a decision or request changes.

## Chatbot Guidance Terms

### Unsupported Question
Definition:
A user question that cannot be answered from the current documentation.

Expected chatbot behavior:
The chatbot should avoid guessing and should direct the user to support or documentation when information is unavailable.
