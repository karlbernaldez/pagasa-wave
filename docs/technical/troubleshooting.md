# Troubleshooting Guide

## Chatbot Issues

### Invalid API key
Possible causes:
- incorrect backend API key
- expired key
- malformed environment variable
- deployment environment mismatch

### Chat service unavailable
Possible causes:
- backend service unavailable
- missing configuration
- API outage

## Project Issues

### Project is read-only
Possible causes:
- submitted workflow state
- under review state
- approved state
- published state

### Cannot submit project
Possible causes:
- incomplete project data
- invalid workflow state
- expired session
- permission restrictions

### Cannot publish project
Possible causes:
- insufficient permissions
- invalid workflow state
- review requirements not met

## Access Issues

### Login problems
Possible causes:
- invalid credentials
- expired session
- authentication failure

### Missing features
Possible causes:
- role restrictions
- permission configuration
- account limitations

## Map Issues

### Map not loading
Possible causes:
- network issue
- map service problem
- browser issue
