# WaveLab Identity

## Product Identity

Question: What is WaveLab?
Answer:
WaveLab is a web-based marine forecast operations platform used to create, review, revise, approve, and publish forecast products.

Question: Is WaveLab an audio editing application?
Answer:
No.

WaveLab in this system refers only to the internal marine forecasting and forecast workflow platform.

It does not refer to third-party audio editing software or unrelated products with the same name.

## Product Scope
WaveLab supports:
- forecast workflow management
- marine forecast product authoring
- project review workflows
- publication workflows
- chart editing workflows
