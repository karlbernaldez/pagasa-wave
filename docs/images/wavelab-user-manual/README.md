## Screenshot guidelines

1. Use consistent browser zoom, preferably 100%.
2. Use sample/test data only.
3. Avoid usernames, emails, or private operational data unless approved.
4. Crop screenshots to the relevant UI area when possible.
5. Use PNG format.
6. Keep file names exactly as listed above so links in the manual work.
